• Kernel:
  - Huge thanks to Sultan Alsawaf (kerneltoast). Most of the scheduler, power and driver work here comes from his kernel.
  - Merge android14-6.1-lts (6.1.177).
  - Import google-modules and Pixel device trees from android16-qpr1.
  - Update the Mali GPU driver to r54p3 for the Android 17 GPU blobs.
  - Improve Mali DVFS utilization accuracy.
  - Replace Google's vendor scheduler with CASS (Capacity Aware Superset Scheduler).
  - Introduce a new CPU energy model measured with freqbench.
  - schedutil: Ignore the rate limit when scaling up, and lower it to 2ms.
  - schedutil: Use the frequency just below the target when the two are close.
  - schedutil: Run frequency changes on the CPU that asks for them. Idle CPUs woken just to change frequency went from 45 to 0 per 30 seconds, and changes no longer wait up to 220us for a sleeping CPU to wake up.
  - Reduce the PELT half-life from 32ms to 16ms, so load changes are picked up faster.
  - Revert Google's PELT multiplier and TEO util-awareness.
  - Disable TTWU_QUEUE and cache-hot buddy, and set migration cost to zero to make use of the shared L3.
  - Don't migrate a lone task to a bigger CPU for no reason, or keep tasks on big CPUs for throughput.
  - Compile out NUMA code and resolve scheduler features at compile time.
  - Reject idle entry when a reschedule is already pending.
  - Fix ADPF performance hints failing on UI threads. Hundreds of failed hint calls went to none.
  - Stop the power HAL from retrying writes to missing Pixel scheduler files and from spamming logd.
  - Emerald Hill zram: Overhaul the request queue, wait on interrupts instead of polling, use a real-time compression thread and a 4096-page hardware FIFO.
  - Disable proactive compaction and watermark boosting.
  - Enable lazy RCU and power efficient workqueues by default.
  - Wi-Fi: Process packets in a real-time thread instead of a tasklet, and stop pinning it to CPU0.
  - Wi-Fi: Cut the OOB wakelock timeout from 500ms to 100ms, and drop a wakelock timeout from the unlock path.
  - Wi-Fi: Disable debug bloat, logging and packet logging.
  - Modem: Stop tpmon from boosting CPU, INT and memory frequencies or setting CPU affinity, and stop pinning its workers to CPU2.
  - Display: Stop busy waiting for CGC DMA, sleep idle while waiting, and don't count flip waits as CPU load.
  - Display: Disable heavy DMA debug IRQs and stub out debug prints.
  - Memory bus: Port Google's zuma fix so PM QoS updates no longer reset the frequency governor's sampling. Its sampling timer went from 136 to 62 runs a minute at idle.
  - Memory bus: Keep the frequency governor thread on its timer's CPU. Wakeups that pulled in another idle CPU went from 67 of 68 to none.
  - ACPM: Don't busy wait when sending data from process context.
  - Align the softlockup and hardlockup watchdog timers, so all CPUs wake up for them together once every 4 seconds. That's 120 interrupts at 15 moments a minute instead of 183 at 75.
  - Turn off the CAN bus statistics timer, which woke a CPU up 60 times a minute for a bus phones don't have.
  - Make the KFENCE sampling timer deferrable, so it no longer wakes up idle CPUs.
  - Always use LSE atomics and hardware CRC32.
  - Avoid dynamic memory allocation in SELinux, BPF and prctl hot paths.
  - Speed up mbcache entry creation and sync_file ioctls.
  - Give the thermal IRQ worker maximum real-time priority.
  - Reduce the freezer timeout to 1 second.
  - Use BBR for TCP congestion control.
  - Switch the IOVA allocator to the vendor hooks.
  - Stop Google's metrics from hooking IRQs, context switches and perf events.
  - Disable UFS command logging and stats collection, and Mali Pixel stats.
  - Stop building test modules.
  - Silence logspam in AOC audio, CS35L41, WM ADSP, haptics, camera (LWIS), PCIe, I2C, display, binder and Wi-Fi drivers. The idle kernel log went from 295 to 5 lines per 30 seconds.
  - Fix memory leaks, out-of-bounds accesses and probe errors in Wi-Fi, battery, charger, haptics, touch, MFC, BCL, BTS, gvotable and regulator drivers.
